Trabalho Prático 1 - AEDS II

Instruções de uso:

Para compilar o programa, basta abrir o terminal e executar make.

Para executar o programa, basta digitar make run no terminal.

Feito isso, um Menu interativo será exibido. Nele, contém 6 opções, sendo elas:

1. Inserir dados nos indices invertidos
2. Imprimir Hash
3. Imprimir PATRICIA
4. Buscar termos na Hash
5. Buscar termos na PATRICIA
6. Encerrar o programa

Basta digitar o número referente à operação desejada, e seguir as instruções fornecidas caso necessário (isso porque a opção 1, por exemplo, solicita o nome do arquivo de entrada principal.)
